# Contribuer

- **Branches** : en anglais, concises, `features/<subject>` ou `fix/<subject>` (ex. `features/srt-export`).
- **Commits** : en anglais, concis, commencent par `feat:` ou `fix:` (ex. `feat: add SRT export`).
- **Description de PR** : en français, liste à puces de ce qui est fait, rien d'autre. Pas de blabla, pas de texte généré par IA.
- **Validation** : toute PR doit être validée par quelqu'un d'autre que son auteur avant fusion.
- **Versions** : respecter les versions en place ; les mettre à jour pour une raison de sécurité ou de pertinence technique.
- **Sécurité** : aucune clé ni secret dans le dépôt, aucune faille introduite.

Exemple de description :

```
- Ajoute l'export SRT des sous-titres dans le studio
- Corrige le zoom qui sautait sur les extraits de moins de 5 s
```
